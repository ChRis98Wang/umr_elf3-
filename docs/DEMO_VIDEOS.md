# Actual official UMR demo recordings

Three complete clips, 151 frames each at 50 Hz. GIF previews show every fourth
frame at 12.5 Hz; MP4s preserve all 151 frames. These are **kinematic** results,
not trained controllers, physical simulations of task execution, or real hardware.

## What they establish

Human pose parameters → official learned surface correspondence → official
retargeting and LQR filter → ELF3 final qpos → read-only checks → MuJoCo rendering.
The robot trajectory is **not** manually keyed or generated by the human-test
script. No old unofficial IK or local B-spline optimizer is used on this path.

All three have zero URDF angle/speed excess in the sampled output. The lowest
visual foot point is approximately +15.4 mm above the floor. Original enabled
URDF collision checks report no self-penetration, but some ELF3 visual links
lack colliders: this is **not** a complete self-collision clearance check.
The examples do not prove source fidelity, grounded foot contact, balance,
physical tracking, box manipulation or full-library quality.

## Source and publication scope

The input motions are deterministic, self-authored SMPL-X pose parameter tests,
not AMASS or LAFAN1 clips. Human floor placement is part of constructing the test
source; robot outputs are never shifted to hide floor error. Rendering uses the
ELF3 appearance, but the repository does not redistribute ELF3 meshes or SMPL-X
model files. The [media manifest](media/manifest.json) records input/result/media
hashes and measured screening values without private machine paths.

Robot asset attribution: [BXI ELF3](https://github.com/bxirobotics/bxi_controller_ros2),
revision `1c9954040d114b3ff5e133b3611c5b327d19d029`.
Retargeter: [official UMR](https://github.com/hanyang9/UMR), revision `e24fc070`.
Human model: [SMPL-X](https://smpl-x.is.tue.mpg.de/), Pavlakos et al., CVPR 2019.
These are noncommercial research visualizations; see [NOTICE](../NOTICE.md).

## Reproduction

After the [official setup](OFFICIAL_UMR.md), generate the human test inputs:

```bash
local/venv_umr_official/bin/python scripts/make_official_demo_sources.py \
  --body-model /absolute/path/to/SMPLX_NEUTRAL_2020.npz \
  --output local/authored_sources
```

Run `run_official_elf3.py prepare` and `run` separately for each resulting NPZ,
then `preview_official_elf3.py` for each completed run. Finally,
`export_official_demo_media.py` can export exactly these three named examples
to a **new** media directory after checking their source, run and video hashes.
It does not export AMASS clips or robot trajectory arrays.
